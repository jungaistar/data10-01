## 2차 — 로그 샘플과 요청 (2026-10-21)

첨부: 로그 CSV 1개(3,600행, 2026-10-01 09:00:00 ~ 10:59:58, 2초 간격, 프레스 P1 · 금형 M-01, 「데이터 구분」 칸 값 「모의 데이터」). 수강생이 만든 모의 데이터이며, 리포에는 원본 대신 같은 형식으로 새로 만든 가상 샘플(`samples/센서로그_샘플_2026-10-21.csv`)을 둡니다.
열: 일자(yyyy-mm-dd hh:mm:ss) · 프레스 · 프레스 종류 · 금형명 · 프레스 누적 타수 · 금형 타수 · 전류(A) · 전압(V) · 온도(℃) · 진동(mm/s) · 데이터 구분

> 프레스 전류/전압/온도/진동은 프레스 설비의 센서로부터 2초 단위로 송신되는 데이터이고, 프레스 타수는 10초에 1타씩 올라가는 형태의 로그데이터입니다. 이러한 형태로 대시보드상에 시각화를 하고, 각 값들마다 차트에 +,- 3 시그마 관리선으로 관리를 하고자 합니다.

## v2.1 요청 (2026-11-10)

> 기존에 대시보드에 요청드려서 반영된 내용중 금형 타수관리, 교체주기, 오버홀 알림 기능은 삭제하고
> 프레스의 전압, 전류, 진동, 온도 실시간 모니터링을 통한 정상/이상상태 예측하는 기능만을 고도화 하려고 합니다.
> 그래서 대시보드의 좌측 탭에서 금형 타수 교체, 오버홀 알림, 월별 타수 보고서 탭은 삭제 부탁드립니다.
> 추가로 머신러닝 탭을 추가해서 전압,전류,진동,온도 데이터에서 정상상태, 이상상태(고장이력) 저장된 데이터에서 라벨링을 할수 있게 페이지 생성을 부탁드립니다.

첨부 그림: 「정비·고장 이력 테이블 예시 (maintenance_log)」 — log_id · equipment_id · found_at · fixed_at · symptom · failure_part · cause · action 의 8칸 표(예시 2행). 리포에는 그림의 값을 옮기지 않고, 같은 칸 구성으로 새로 만든 가상 이력(`samples/가상_정비고장이력_maintenance_log.csv`, 3건)을 둡니다.
